インストールしてからしばらくはアップデートが成功していたが、とある時からアプデートが成功しなくなってしまったのでメモ。以下の手順で更新可能。

1. **設定と変更をバックアップする**
  ```
  backup_dir="$HOME/omarchy-recovery-$(date +%Y%m%d-%H%M%S)"
  mkdir -p "$backup_dir"
  cp -a ~/.config "$backup_dir/config"
  git -C ~/.local/share/omarchy diff --binary > "$backup_dir/local-changes.patch"
  
  ```

  
2. **ローカル変更を退避して、更新先を切り替える**
  ```
  cd ~/.local/share/omarchy
  git stash push -m "Before Omarchy recovery"
  git fetch origin
  git switch rc
  omarchy update
  
  ```
